## 1. Hızlı Başlangıç

GAVF uyumlu bir uygulama geliştirmek için:

1. **Standardı okuyun**: 0101 (çekirdek) + ilgili S katmanları
2. **Öz değerlendirme yapın**: 0301 kontrol listesi
3. **Uygulayın**: Prompt taksonomisi (0106), alıntı şeması (0107), skor algoritması (0104)
4. **Doğrulayın**: Test senaryoları (0304) ile uyumluluğu test edin
5. **Beyan edin**: Uyumluluk beyanınızı yayınlayın

## 2. Asgari Gereklilikler (Temel)

| Gereklilik | Detay |
|------------|-------|
| Prompt | En az 5 prompt, 3 farklı boyuttan |
| Motor | En az 1 AI motoru |
| Örnekleme | n=3, temp=0 |
| Skor | En az varlık + konum bileşenleri |
| Fidelite | Tüm skorlarda etiket zorunlu |
| Alıntı | En az doğrudan (direct) alıntı desteği |
