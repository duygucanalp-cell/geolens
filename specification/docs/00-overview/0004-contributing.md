## 1. Nasıl Katkı Yapılır?

1. GitHub'da bir fork oluşturun
2. Değişikliklerinizi yapın
3. PR açın ve değişiklik tipini belirtin (patch/minor/major)
4. Maintainer incelemesini bekleyin
5. İnceleme sonrası PR birleştirilir veya geri bildirim verilir

## 2. PR Kontrol Listesi

- [ ] Değişiklik tipi doğru etiketlenmiş (patch/minor/major)
- [ ] ADR eklenmiş (minor/major için zorunlu)
- [ ] Changelog güncellenmiş
- [ ] İlgili dokümanlardaki referanslar güncellenmiş

## 3. Davranış Kuralları

- Tüm katkılar yapıcı ve saygılı olmalıdır
- Standart kararları veri ve mantık temellidir, duygu temelli değil
- Geri bildirim süresi: 14 gün (minor), 30 gün (major)
