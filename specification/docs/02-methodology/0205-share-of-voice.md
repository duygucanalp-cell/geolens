## 1. Amaç

Bir markanın, tanımlı rakip seti içindeki göreceli görünürlük payını ölçer.

## 2. Hesaplama

```
Ses Payı = (Marka Görünürlük Skoru / Toplam Rakip Skorları Toplamı) × 100
```

## 3. Yorumlama

| Ses Payı | Anlamı |
|:--------:|--------|
| > %40 | Pazar lideri |
| %20–40 | Güçlü oyuncu |
| %10–20 | Orta seviye |
| <%10 | Zayıf / yeni oyuncu |
